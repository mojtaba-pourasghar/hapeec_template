# صفحه اصلی هپیک — بازنویسی دیجی‌کالا با پالت و محتوای هپیک

چیدمان، ترتیب بخش‌ها و اندازه‌های این صفحه بخش‌به‌بخش از کپچر دیجی‌کالا در همین ریپو
گرفته شده‌اند (`tools/site-capture/captures/www.digikala.com`). رنگ، وردمارک، متن و
کاتالوگ از هپیک است و همه‌چیز حول موتورسیکلت و قطعه می‌چرخد.

طراحی قبلی (`design/home-redesign`) کامل حذف شد.

---

## فایل‌ها

| فایل | کار |
|---|---|
| `build.py` | از `data/home.json` فایل `index.html` را می‌سازد |
| `index.html` | خروجی ساخت — دستی ویرایش نکنید |
| `data/home.json` | محتوای واقعی کاتالوگ: محصول، قیمت، تخفیف، دسته، برند، استوری، مجله |
| `extract.py` | اگر کپچر تازه‌ای گرفتید، `home.json` را دوباره می‌سازد |
| `assets/css/tokens.css` | پالت رسمی + مقیاس فاصله، تایپوگرافی، شعاع و عرض گارد |
| `assets/css/home.css` | استایل کامل صفحه |
| `assets/js/home.js` | رفتار صفحه، بدون وابستگی خارجی |
| `assets/img/hapeec-wordmark*.png` | وردمارک انگلیسی، بریده‌شده از لوگوی ارائه‌شده |

```bash
cd design/hapeec-home && python3 build.py
```

## پالت

| توکن | کد | کاربرد |
|---|---|---|
| `--navy` | `#0D1C31` | متن، تیتر، هدر، فوتر |
| `--orange` | `#EC6A14` | بلوک کمپین، نشان تخفیف، تأکید |
| `--orange-dark` | `#C2530A` | لینک متنی و hover روی زمینه روشن |
| `--white` | `#FFFFFF` | پس‌زمینه صفحه و کارت |
| `--gray` | `#F3F5F8` | باکس جستجو، چیپ‌ها، قاب دایره‌ای دسته‌ها |
| `--steel` | `#6B6B6B` | متن فرعی |

پس‌زمینه کل صفحه، از بنر اعلان تا فوتر، `#FFFFFF` خالص است. هیچ بخشی زمینه رنگی ندارد
جز بلوک نارنجی «شگفت‌انگیز» که خودش یک بنر است. هیچ بردری در کل صفحه نیست جز دو
جداکننده عمودی ناوبری.

## نقشه بخش‌ها (در برابر دیجی‌کالا)

| دیجی‌کالا | هپیک |
|---|---|
| بنر تمام‌عرض بالای صفحه | همان، لبه تا لبه |
| هدر: لوگو، باکس جستجوی گرد خاکستری، زنگوله، «ورود \| ثبت نام» با کادر، سبد | همان ترتیب + دکمه دوربین جدا، سمت چپ باکس جستجو |
| ردیف ناوبری: ☰ دسته‌بندی کالاها \| میان‌برها \| «در دیجی‌کالا بفروشید!» | همان، با «در هپیک بفروشید!» نارنجی. **دو سر این ردیف گارد محتوای کل صفحه است.** |
| اسلایدر تمام‌عرض با نقطه‌های پایین | همان |
| ردیف دایره‌های میان‌بر + «بیشتر» | ۸ استوری واقعی + دایره نهم «بیشتر» هم‌اندازه |
| بلوک قرمز «شگفت‌انگیز»: پنل کناری با نشان ٪، تایمر، «مشاهده همه» + ریل کارت سفید | همان بلوک، نارنجی `#EC6A14`، با تایمر واقعی کمپین |
| ردیف چهار بنر | همان، بدون هیچ متنی زیرشان |
| «دسته‌بندی‌ها»: دایره‌های عکس واقعی | ۱۰ دسته با **عکس واقعی** (کلاه کاسکت، دستکش، لاستیک، روغن، موتور) |
| ردیف محصول با چیپ «مشاهده همه» | «خرید موتورسیکلت»، «قطعات و لوازم جانبی»، «پیشنهادات این هفته» |
| ردیف دو بنر عریض | همان |
| «پرفروش‌ترین‌ها»: گرید فشرده شماره‌دار | همان، با شماره‌های نارنجی |
| ردیف لوگوی برندها | همان، بدون نام و بدون کادر |
| فوتر: ردیف آیکون خدمات، ستون‌ها، خط پایین | همان |

بخش «خرید بر اساس موتور شما» (چیپ‌های سازگاری قطعات) اضافه‌ی هپیک است؛ معادلی در
دیجی‌کالا ندارد ولی هسته‌ی کار این پلتفرم است.

### یک کارت محصول، همه‌جا

هر ۴۰ محصول صفحه از تابع `product_card()` در `build.py` می‌گذرد — یک پیاده‌سازی، نه
بیشتر. در نسخه Blade هم همین قید باید برقرار بماند (یک
`components/product-card.blade.php` و `@include` در هر بخش).

- کارت سفید، بدون بردر، بدون سایه، بدون قاب دور عکس، بدون «افزودن به سبد».
- عکس با `object-fit: contain` و نسبت ۱:۱ — ۵۶٪ ارتفاع کارت روی دسکتاپ.
- عنوان با `line-clamp: 2` و ارتفاع ثابت تا ردیف به‌هم نریزد.
- نشان تخفیف و قیمت خط‌خورده **فقط وقتی کاتالوگ واقعاً تخفیف دارد**، بعد قیمت نهایی.
- کل کارت لینک صفحه محصول است، بدون کنترل تودرتو.

### آیکون‌ها

یک مجموعه outline به‌صورت SVG درون‌خطی در `build.py` (دیکشنری `ICONS`). هیچ آیکون
توپری در صفحه نیست و وابستگی تازه‌ای اضافه نشده.

## اتصال به تم Laravel

۱. `tokens.css` و `home.css` را در `themes/frontend/hapeec/assets/css/` بگذارید و بعد
   از `base.css` صدا بزنید؛ `home.css` فعلی تم جایگزین می‌شود.
۲. `home.js` را در `themes/frontend/hapeec/assets/js/` بگذارید.
۳. وردمارک‌ها را در `assets/images/Logo/` بگذارید و متن `HAP<em>EEC</em>` هدر و فوتر
   را با `<img>` عوض کنید.
۴. هر بخش `index.html` را به partial متناظرش منتقل کنید؛ آدرس‌ها همان چیزی است که
   اپلیکیشن الان تولید می‌کند، پس route و کنترلر تغییری لازم ندارد.

| کنترل | مقصد |
|---|---|
| جستجو | `GET /fa/products?q=` |
| جستجو با عکس | مودال `#vcamModal` تم؛ در نبودش آپلود فایل به `/fa/products` |
| ورود / ثبت‌نام · سبد · اعلان | `/fa/login` · `/fa/cart` · `/fa/notifications` |
| شگفت‌انگیزها | `/fa/flash-sale` |
| دسته‌بندی · برند | `/fa/products?categories=…` · `?brands=…` |
| چیپ موتور | `/fa/products?type=parts&motorcycle_model_id=…` |
| کارت محصول · مجله | `/product/{slug}` · `/fa/blog/{slug}` |
| فروشندگان | `/fa/seller-center/login` |

## محدودیت‌ها

۱. **عکس از بخش موتور دیجی‌کالا نشد.** `digikala.com` و CDN آن از این کانتینر مسدودند و
   کپچر موجود فقط صفحه اصلی دیجی‌کالاست — بخش موتور و قطعه داخلش نیست. پس عکس
   محصول، دسته‌بندی و بنرها از عکس‌های واقعی کاتالوگ خود هپیک برداشته شده‌اند.
   برای کپچر بخش موتور دیجی‌کالا باید `digikala.com` به شبکه مجاز سشن اضافه شود.
۲. **لوگوی برندها.** نه کاتالوگ هپیک لوگو دارد نه کپچر دیجی‌کالا لوگوی برند موتوری.
   لوگوی هوندا/یاماها ساختنی نیست، پس فعلاً نام برند تمیز رندر می‌شود؛ به‌محض پر شدن
   `brands[].logo` همان‌جا `<img>` می‌آید.
۳. **صفحه فهرست استوری** در اپلیکیشن نیست، پس «بیشتر» بقیه استوری‌ها را همان‌جا باز
   می‌کند به‌جای لینک مرده.
۴. **شبکه‌های اجتماعی فوتر** در سایت فعلی `href="#"` هستند؛ همان‌طور ماندند.
۵. **فونت.** هیچ فونتی دانلود یا embed نشده؛ استک به `IRANSansX / IRANSans / Vazirmatn`
   موجود در تم تکیه می‌کند.

## بررسی‌های انجام‌شده

با Chromium در ۳۲۰، ۳۹۰، ۷۶۸، ۱۰۲۴ و ۱۴۴۰ پیکسل:

- `scrollWidth == clientWidth` در همه عرض‌ها → بدون سرریز افقی.
- هیچ `section`/`header`/`footer`/`nav` پس‌زمینه غیرسفید ندارد.
- هیچ عنصری بردر قابل‌مشاهده ندارد (جز دو جداکننده عمودی ناوبری).
- کارت محصول: `border-width: 0`, `box-shadow: none`, `background: #FFFFFF`.
- تصویر محصول ۵۲–۵۸٪ ارتفاع کارت (۶۹٪ فقط در ۷۶۸ پیکسل که کارت‌ها پهن‌ترند).
- ۴ بنر، ۱۰ دسته و ۹ استوری در همه عرض‌ها رندر می‌شوند.
- فلش اسکرول برندها با هیچ لوگویی هم‌پوشانی ندارد.
- اسلایدر، تایمر، «بیشتر»، منوی کشویی (+Esc)، و پیمایش ریل محصول و برند تست شده‌اند.
- هیچ خطای console یا `pageerror` وجود ندارد.
