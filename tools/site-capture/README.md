# site-capture

ابزاری که آدرس یک سایت را می‌گیرد، صفحه‌هایش را پیدا می‌کند و از **هر نوع صفحه فقط یک نمونه**
را در نسخه **دسکتاپ (۱۴۴۰ پیکسل)** و **موبایل (۳۹۰ پیکسل)** تمام‌صفحه عکس می‌گیرد و در پوشه
`captures/` کنار خود ابزار ذخیره می‌کند. بعد آن پوشه را پوش می‌کنید تا از روی عکس‌ها
سایت ساخته شود.

## حافظه: هیچ صفحه‌ای دوبار عکس گرفته نمی‌شود

همه چیز در `captures/<دامنه>/manifest.json` ثبت می‌شود و هر اجرای بعدی از همان‌جا ادامه می‌دهد:

- صفحه‌ها و قالب‌هایی که قبلاً عکس گرفته شده‌اند دوباره گرفته نمی‌شوند.
- اگر وسط کار «توقف» زدید یا برنامه بسته شد، دفعه بعد از همان لینک ادامه می‌دهد.
- اگر قبلاً فقط دسکتاپ گرفته بودید و حالا موبایل هم می‌خواهید، فقط نمای جاافتاده اضافه می‌شود.
- در رابط، با وارد کردن آدرس، عکس‌های قبلی همان سایت با برچسب «قبلی» نمایش داده می‌شوند.
- برای شروع از صفر: تیک «از اول» یا `--fresh` (عکس‌های قبلی آن سایت پاک می‌شود).

پس می‌توانید چند بار کوتاه اجرا کنید (مثلاً هر بار `--max 20`) تا کل سایت پوشش داده شود.

## فقط یک صفحه مشخص

در بخش **«فقط یک صفحه مشخص»** آدرس صفحه را بدهید و «فقط همین صفحه» را بزنید. از همان صفحه
(دسکتاپ و موبایل) عکس گرفته می‌شود، بدون گشتن در سایت و بدون حذف تکراری‌ها. چند آدرس از یک
سایت هم می‌شود، هر خط یکی. اگر آن آدرس قبلاً گرفته شده، عکس جدید جای قبلی را می‌گیرد؛ بقیه
صفحه‌ها و صف ادامه کار دست نمی‌خورند.

از خط فرمان: `npm run capture -- https://www.example.com/product/123 https://www.example.com/cart --only`

## حذف یک صفحه

کنار هر صفحه در رابط دکمه **«حذف»** هست (دو بار بزنید تا تأیید شود). فولدر عکس‌های آن صفحه
پاک می‌شود و از فهرست و `manifest.json` بیرون می‌رود؛ اگر فولدرش از قبل پاک شده باشد، فقط از
فهرست حذف می‌شود. اجرای بعدی ممکن است دوباره نمونه‌ای از همان نوع صفحه بگیرد (مثلاً اگر عکس
قبلی خراب بود، با حذف و «شروع» دوباره گرفته می‌شود).

## اگر «شروع» عکسی نگرفت

- پیام‌های قرمز زیر «نتیجه» را بخوانید؛ ابزار حالا هر صفحه‌ای که باز نشود را با دلیل نشان می‌دهد.
- اگر سایت در مرورگر خودتان باز می‌شود ولی ابزار خطا می‌دهد یا عکس‌ها صفحه «در حال بررسی
  مرورگر» را نشان می‌دهند: در «تنظیمات بیشتر» تیک **«نمایش مرورگر»** را بزنید (یا `--headed`).
- اگر پیام «مرورگر Chromium نصب نیست» آمد: `npx playwright install chromium`.
- صفحه‌هایی که باز نشدند ذخیره می‌شوند و در اجرای بعدی اول دوباره امتحان می‌شوند.
- اگر پیام «صفحه جدیدی پیدا نشد» آمد، یعنی همه نوع صفحه‌ها قبلاً گرفته شده‌اند؛ تیک «از اول»
  یا حذف صفحه‌ها را امتحان کنید.

## از هر بخش فقط یک نمونه

ابزار هر صفحه را باز می‌کند و **قالب** آن را (اجزای سازنده صفحه، فیلترها، فرم‌ها، متن بلند)
با صفحه‌هایی که قبلاً گرفته مقایسه می‌کند. اگر قالب یکی باشد، عکس نمی‌گیرد و می‌گذرد.
مثلاً وقتی یک صفحه دسته‌بندی گرفته شد، دسته‌بندی‌های دیگر، نتایج جستجو و صفحات فیلترشده
رد می‌شوند؛ از هزاران محصول هم فقط یکی گرفته می‌شود. صفحه‌های ردشده در `manifest.json`
(بخش `skipped`) ثبت می‌شوند. برای خاموش کردن این رفتار: تیک «از هر قالب فقط یک نمونه» یا `--no-dedupe`.

رابط کاربری با React است. عکس‌برداری را یک سرور کوچک Node با Playwright (مرورگر Chromium)
انجام می‌دهد؛ چون یک صفحه وب به تنهایی نمی‌تواند از سایت دیگری عکس بگیرد.

## فقط صفحه‌های مهم (پیش‌فرض روشن)

هدف، صفحه‌های فروشگاهی است؛ ابزار آن‌ها را به این ترتیب جلو می‌اندازد:
صفحه اصلی، **نتیجه جستجو** (خودش در جعبه جستجوی سایت «لپ تاپ» را می‌زند)، **دسته و فیلتر**،
**محصول**، **سبد خرید** و **پروسه خرید** (قبلش یک محصول به سبد اضافه می‌کند تا خالی نباشد)،
ورود و پنل کاربر، **بلاگ** و مطلب بلاگ، **تماس با ما** و **قوانین و مقررات**.

- از **لندینگ‌ها فقط یکی** گرفته می‌شود؛ از «درباره ما»، «سوالات متداول» و صفحه‌های ناشناخته هم یکی.
- هر نوع صفحه نمونه خودش را دارد، حتی اگر قالبش شبیه نوع دیگری باشد (مثلاً پنل و پروسه خرید).
- اگر لینک یک نوع صفحه پیدا نشد، آدرس‌های رایج (`/cart`، `/contact-us`، `/rules`، `/blog`...) امتحان می‌شوند.
- در پایان، نوع صفحه‌هایی که پیدا نشد اعلام می‌شوند تا آدرسشان را در «آدرس‌های اضافه» بدهید.
- پنل کاربر بدون ورود به حساب معمولاً به صفحه ورود می‌رود؛ همان صفحه ورود ثبت می‌شود.

برای گرفتن همه نوع صفحه‌ها: تیک «فقط صفحه‌های مهم» را بردارید یا `--all`.

## نصب (فقط بار اول)

پیش‌نیاز: [Node.js](https://nodejs.org) نسخه ۱۸ یا بالاتر.

```bash
cd tools/site-capture
npm run setup        # نصب وابستگی‌ها + دانلود مرورگر Chromium
```

## اجرا با رابط گرافیکی

```bash
npm run dev
```

مرورگر خودکار روی `http://localhost:5173` باز می‌شود. آدرس سایت را بدهید و «شروع» را بزنید.
پیشرفت کار و پیش‌نمایش عکس‌ها زنده نمایش داده می‌شود.

## اجرا از خط فرمان (بدون رابط)

```bash
npm run capture -- https://www.technolife.com --max 60 --per-pattern 2
```

| گزینه | کار |
|---|---|
| `--max 40` | حداکثر صفحه **جدید** که در این اجرا عکس گرفته می‌شود |
| `--visits 150` | حداکثر صفحه‌هایی که در این اجرا برای بررسی قالب باز می‌شود |
| `--per-pattern 3` | از هر الگوی آدرس چند صفحه باز شود (قبل از بررسی قالب) |
| `--no-dedupe` | صفحه‌های هم‌قالب را هم عکس بگیر |
| `--seed <url>` | آدرس اضافه برای شروع (چند بار قابل تکرار) |
| `--depth 4` | حداکثر عمق دنبال‌کردن لینک‌ها |
| `--desktop-only` / `--mobile-only` | فقط یک نما |
| `--png` | PNG به‌جای JPG (حجم بیشتر) |
| `--slice 2000` | ارتفاع هر تکه عکس |
| `--keep-query` | آدرس‌های دارای `?` را صفحه جدا حساب کن |
| `--login` | مرورگر باز می‌شود؛ وارد حساب شوید، بقیه کار خودکار است |
| `--login-url <url>` | آدرس صفحه ورود (اگر با صفحه اصلی فرق دارد) |
| `--login-only` | فقط ورود و ذخیره جلسه، بدون عکس‌برداری |
| `--auth` | از جلسه ذخیره‌شده قبلی استفاده کن |
| `--only` | فقط همین آدرس‌ها (چند آدرس پشت سر هم)، بدون گشتن در سایت |
| `--all` | همه نوع صفحه‌ها، نه فقط صفحه‌های فروشگاهی (لندینگ‌ها هم بدون محدودیت) |
| `--fresh` | عکس‌های قبلی این سایت را فراموش کن و از اول بگیر |
| `--headed` | مرورگر را هنگام عکس‌برداری نشان بده (برای سایت‌هایی که مرورگر پنهان را مسدود می‌کنند) |

## عکس از پنل کاربری (ورود خودکار، فقط از خط فرمان)

دکمه «شروع» در رابط همیشه **بدون ورود به حساب** کار می‌کند و منتظر هیچ جلسه‌ای نمی‌ماند.
عکس از پنل کاربری فقط با خط فرمان گرفته می‌شود:

1. `npm run capture -- https://www.example.com --login`
   اگر صفحه ورود آدرس جدا دارد: `--login-url <آدرس>`.
2. مرورگر روی سایت باز می‌شود؛ مثل همیشه وارد حساب شوید (پیامک، رمز، ...).
3. **کار دیگری لازم نیست.** ابزار به محض ورود، جلسه را تشخیص می‌دهد، ذخیره می‌کند، پنجره را
   خودش می‌بندد و عکس‌برداری را با همان حساب شروع می‌کند. لینک‌های پنل (پروفایل، سفارش‌ها،
   آدرس‌ها، علاقه‌مندی‌ها و...) در صف جلو می‌افتند.

اگر قبل از بسته‌شدن خودکار، صفحه‌ای از پنل را باز کنید، آن صفحه هم ثبت و حتماً عکس گرفته
می‌شود. اگر ورود تشخیص داده نشد، پنجره را خودتان ببندید؛ جلسه باز هم ذخیره می‌شود.
دفعه‌های بعد برای استفاده از همان جلسه: `--auth`.
ابزار لینک‌های خروج از حساب را باز نمی‌کند.

```

  pages/001-home/

    mobile-full.jpg
    mobile-part01.jpg ...

```

## نکته‌ها

- ابزار فقط لینک‌های همان دامنه را دنبال می‌کند و بین صفحه‌ها مکث می‌کند تا به سایت فشار نیاید.
- فایل‌های `auth.json` (نشست ورود شما) و `visited.json` (آدرس صفحه‌های پنل، ممکن است شماره
  سفارش داشته باشد) در گیت نادیده گرفته می‌شوند؛ آن‌ها را پوش نکنید. عکس‌های پنل هم ممکن است
  نام، شماره موبایل یا آدرس شما را نشان دهند؛ قبل از پوش نگاهشان کنید.
- حالت‌های تعاملی مثل مگامنوی باز را ابزار خودکار نمی‌گیرد؛ اگر لازم است، دستی اسکرین‌شات
  بگیرید و کنار بقیه در همان پوشه بگذارید.
- این عکس‌ها فقط مرجع چیدمان و ساختارند؛ متن، عکس و لوگوی سایت مرجع در سایت فیبسو کپی نمی‌شود.
